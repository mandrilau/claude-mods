# mandrilau-claude-mods

Guilherme's own Claude Code mods.

- **mandribar**: a progress bar above the prompt for every prompt, with an animated Claude crab, particle trails, fills, outfits and a `/mandribar` settings pane.
- **mandricrew**: a crab per subagent, with hover info and a `/mandriCrew` details pane. mandribar draws these crabs at the end of its bar.

`mandriBar/hooks/crew-view.tsx` is a copy of `mandriCrew/hooks/view.tsx`: keep them identical.
