# mandricrew

A pixel Claude crab for every subagent Claude starts, so you can see the crew at work.

- Each crab holds a prop for the tool its agent runs and wears an outfit by agent type (a cap for Explore, a wizard hat for Plan).
- A pulsing blue dot while it works, green when done, red with a sad face when it fails.
- Hover a crab for its task, current tool, time and tool count; its details button opens a pane with a header card, the crew, a timeline of recent tool calls, the prompt it was given and its final report, plus a button to open its transcript.

## Use

`/mandriCrew` opens the details pane. Works on its own; with mandribar installed, the crabs ride Claude's working row above the progress bar.
